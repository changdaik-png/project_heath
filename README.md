# 한국의료패널(KHP) 데이터 분석 프로젝트 (sujungpro)

본 프로젝트는 한국의료패널(KHP) 2017년(1기) 데이터와 2022년(2기) 데이터를 분석하기 위한 데이터 전처리, 예측 모델 학습 및 의사결정 시뮬레이션용 웹 대시보드 프로젝트입니다.

## 1. 프로젝트 요구사항

프로젝트의 개발 환경 및 패키지 실행을 위해 아래의 도구가 필요합니다.
* **Python** (3.9 이상 권장)
* **uv** (신속하고 안정적인 파이썬 패키지 관리자)

### 의존성 패키지 (requirements.txt)
* `pandas` - 데이터 핸들링 및 가공
* `pytest` - 코드 검증 및 전처리 로직 테스트
* `scikit-learn` - 분석용 머신러닝 라이브러리
* `streamlit` - 웹 UI 및 시각화 대시보드 구축
* `joblib` - 학습된 기계학습 모델 객체 저장/로드

## 2. 모듈 및 결과물 안내

### ① 전처리 모듈 (`preprocessing.py`)
한국의료패널 SAS 원본 파일을 로드하고 분석 가능한 형태로 가공하는 전처리 함수들이 정의되어 있습니다.
* **`load_sas_data(file_path)`**: KHP SAS 데이터셋(`*.sas7bdat`)을 인코딩 깨짐 없이 안전하게 로드합니다.
* **`preprocess_khp_data()`**: 2017년 및 2022년 가구/개인 데이터를 로드하여 결측치 보정, `HHID` 조인, 나이(40세 이상) 필터링, 만성질환 여부(`CHRONIC_YN`) 파생변수를 추가하고, `PIDWON` 기준으로 병합(교집합 0건 시 가상 매핑 시뮬레이션 적용)하여 `delta_Y`를 계산합니다.

### ② 모델 학습 모듈 (`train_model.py`)
전처리된 데이터를 불러와 미래 의료비 변동액(`delta_Y`)을 예측하는 모델을 학습하고 검증합니다.
* 독립변수: 2017년 기준 `Age` (나이), `Income` (소득), `Chronic_Disease` (만성질환 여부), `Gender` (성별)
* 기계학습 모델: 다중 선형 회귀(Linear Regression) & 랜덤 포레스트 회귀(Random Forest Regressor)

### ③ 학습된 모델 파일 (`model.pkl`)
* `SimpleImputer`와 `RandomForestRegressor`가 결합된 최종 기계학습 예측 파이프라인 직렬화 파일입니다.

### ④ 정책 및 시뮬레이션 웹 대시보드 (`app.py`)
* **개별 시뮬레이터**: 사이드바를 통해 가상 환자의 연령, 소득, 성별, 만성질환 상태를 지정하면 실시간으로 5년 뒤 의료비 변동량을 연산하고, 1:1 맞춤 정책을 시각화합니다.
* **대용량 이중 파일 병합 업로더**: 화면 중앙에 **가구 데이터(e_hh)**와 **개인 데이터(e_ind)**를 각각 업로드받아 식별 키(`HHID`)로 병합하여 예측을 일괄 수행합니다. 1기/2기 등 여러 연도 데이터셋의 변수명을 탐색 및 매핑하고 생년(`BIRTH_Y` 등)을 통한 만 나이 자동 연산과 결측 보정을 지원합니다.
* **상위 10% 위험군 집중 관리**: 예측된 전체 대상자 중 **의료비 증가세(delta_Y)가 가장 심각한 내림차순 상위 10% 위험군만 필터링**하여 대시보드 표에 띄워주고, 상위 10%에 최적화된 다운로드용 CSV 파일을 제공하여 공공의료 복지 재정의 선택적 투입을 지원합니다.

## 3. 설치 및 실행 방법

### 패키지 설치
`uv`를 사용하여 프로젝트의 가상환경을 생성하고 의존성 패키지를 설치합니다.

```bash
# 가상환경 생성 및 의존성 동기화
uv venv
uv pip install -r requirements.txt
```

### 테스트 실행
전처리 연산 정합성을 검증하기 위해 pytest 테스트를 수행합니다.

```bash
# pytest 테스트 수행
uv run pytest test_preprocessing.py
```

### 모델 학습 실행
데이터를 통합하여 가공하고 기계학습 예측 모형을 학습시켜 `model.pkl` 파일을 생성하려면 아래 명령어를 수행합니다.

```bash
# 모델 훈련 및 결과 리포트 출력
uv run python train_model.py
```

### 웹 대시보드 구동
실무자용 시뮬레이션 및 대량 업로드 정책 액션 플랜 제시 대시보드를 띄우기 위해 아래 명령어를 수행합니다.

```bash
# Streamlit 대시보드 실행
uv run streamlit run app.py
```

## 4. 한국의료패널 데이터 프로파일링 결과 요약

1기(2017년)와 2기(2022년) 데이터는 제공되는 데이터 구조와 변수명 설계에 차이가 있어 병합 및 계산 시 매핑 작업이 선행되어야 합니다.

| 핵심 개념 | 2017년 가구 (`t17hh`) | 2017년 개인 (`t17ind`) | 2022년 가구 (`d_hh`) | 2022년 개인 (`d_ind`) | 대소문자 구분 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **개인 ID** | 없음 | **`PIDWON`** | 없음 | **`PIDWON`** | **대문자** |
| **나이** | 없음 | **`A5`** (만 나이) | 없음 | **`BIRTH_Y`, `BIRTH_M`** (직접 계산) | **대문자** |
| **총 의료비** | **`H_MEDICALEXP1`** | **`I_MEDICALEXP1`** | **`H_OOP`** | **`EROOP`, `INOOP`, `OUOOP_1`** | **대문자** |
| **만성질환** | 없음 | **`C2` ~ `C45`** 변수군 | 없음 | **`CD`, `CD1_HTN`, `CD1_DM`** 등 | **대문자** |
